Privacy policy

Last updated: November 15, 2026

This policy describes how the homelab application (“the app”) handles data. The app is a personal, non-commercial project used only by its owner, Anton Lysenko.

Data the app accesses

With the user's explicit consent through Google sign-in, the app requests read-only access to the following Google Health API data: activity and fitness (calories, steps, distance, active minutes, workouts), sleep, and health metrics (resting heart rate, heart-rate variability, blood oxygen, respiratory rate, VO2 max, skin temperature).

How the data is used

The data is used only to show the owner daily summaries of calories burned versus calories eaten, activity, sleep and recovery metrics, in a private Telegram bot and a private dashboard.

Storage and sharing

  • Data is stored only on the owner's home server, in a private database not accessible from the internet.
  • Data is not sold, shared with third parties, used for advertising, or used to train AI/ML models.
  • The app never writes to or modifies Google Health data.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Stored data is deleted from the home server on the owner's request.
